# Задание 2. Подготовка базы знаний

## Формирование базы знаний

Для формирования базы знаний был взят открытый фандом по звездным войнам.

### Скачивание и очистка данных

С помощью скрипта [download_and_clean.py](./download_and_clean.py) Были автоматически выкачаны и очищены страницы с ключевыми персонажами, планетами, технологиями, организациями и событиями.

### Формирование словря замен терминов

Словарь замен ключевых терминов [terms_map.json](./terms_map.json) был сформирован с использованием облачной LLM.

### Замена терминов

Далее с помощью скрипта [replace_terms.py](./replace_terms.py) и словря замен [terms_map.json](./terms_map.json) были заменены все ключевые термины полученных файлов на основе регулярных выражений.
